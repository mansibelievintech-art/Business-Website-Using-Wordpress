# Nexora Digital — WordPress

## Local site

This project contains a bespoke WordPress theme and a small setup plugin that creates the required pages, navigation, and sample blog posts. WordPress and Elementor are loaded by the local runtime.

### Included

- Home, About, Services, Projects, Blog and Contact pages
- Three sample articles
- Responsive navigation and layouts
- Accessible focus states, semantic headings and form labels
- Subtle reveal, hover and statistic animations
- Custom theme with no unnecessary production dependencies
- Elementor installed for page-builder editing and future extension

## Production checklist

Before deployment, replace fictional contact details, connect the inquiry form to WPForms or Contact Form 7, configure an SMTP provider, install one SEO plugin, compress final photography to WebP, enable page caching, and run Lighthouse against the production host.
